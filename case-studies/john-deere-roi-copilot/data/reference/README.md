# Reference data

The JSON files here are the inputs the engine, tests and figures read. They
were extracted from Iowa State University Extension (Ag Decision Maker)
publications.

The original publications are not redistributed in this repository. Download
them from Iowa State to re-run `scripts/extract_isu_reference.py`, and save
them in this folder under the names below.

| Publication | Source | Expected filename |
|---|---|---|
| A3-10, 2026 Iowa Farm Custom Rate Survey | <https://www.extension.iastate.edu/agdm/crops/pdf/a3-10.pdf> | `isu-a3-10-2026-iowa-farm-custom-rate-survey.pdf` |
| A3-29, machinery cost calculator | <https://www.extension.iastate.edu/agdm/crops/xls/a3-29machcostcalc.xlsx> | `isu-a3-29-machinery-cost-calculator.xlsx` |
| A1-20, 2026 Estimated Costs of Crop Production in Iowa | Ag Decision Maker, File A1-20 | `isu-a1-20-2026-estimated-costs-crop-production-iowa.pdf` |

Iowa State serves these files behind a browser challenge, so they must be
downloaded by hand. Tests and figure scripts do not need them.
